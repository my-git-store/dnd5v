# DNDV5 — подготовка публичного тестирования

## Исходное состояние

- Репозиторий: `my-git-store/dnd5v`, remote `origin` подтверждён.
- Рабочая ветка: `feature/nastolka-demo-modules`.
- Исходный общий commit `main` и feature: `71565cfd50f8ee406a791575f95fd41e44f6e110`.
- В исходном `App.vue` был подключён экран НПС, а опубликованный сайт показывал предыдущую сборку с управлением персонажами. Переключение на обычный лист и обновление Pages выполнены в этой задаче.

## Изменения

- Главным экраном стал лист обычного персонажа с вкладками «Основное», «Бой», «Магия / Заклинания», «Инвентарь» и «БИО».
- В верхнюю панель добавлены действия «Создать персонажа», «Сохранить» и «Пройти опрос». Опрос открывается отдельной вкладкой через безопасные `target` и `rel` атрибуты; ответ не отправлялся.
- Для пустого листа добавлено явное состояние создания. Перед заменой активного листа появляется подтверждение.
- Страница объявляет русский язык документа и получила понятное название вкладки браузера.
- Добавлен отсутствовавший локальный favicon; опубликованная HTML-страница больше не должна запрашивать несуществующий файл.
- Проверка хранилища не принимает запись НПС за обычного персонажа и не удаляет несовместимые/старые записи. Перед заменой несовместимая запись архивируется в отдельном ключе localStorage; текущая версия и старые поля проходят проверку формы, предусмотрены узкие преобразования legacy-полей.
- Loader центрирован; значения навыков выровнены в общей правой колонке; длинные названия черт сокращаются, описание в списке не выводится.
- Подключён локальный фон `public/character-sheet-parchment.png` размером 2400×3200. Путь строится от `BASE_URL`, поэтому на Pages используется `/dnd5v/character-sheet-parchment.png`. Файл оставлен в репозитории.
- Текущий `App.vue` не монтирует НПС, бестиарий, планировщик столкновений или компоненты. Отдельных `VITE_ENABLE_*` флагов в актуальной ветке нет; эти экспериментальные разделы не включены в публичную сборку.
- Добавлены шесть unit-тестов безопасного чтения/сохранения, архивирования, legacy-нормализации и отказа от несовместимого NPC payload.

## Проверки

- `npm run typecheck` — PASS.
- `npm test` — PASS, 6 тестов.
- `npm run build` — PASS; сборка Vite завершилась. Осталось предупреждение Vite о размере основного JS bundle около 1.5 MB.
- `git diff --check` — PASS.
- Production build содержит base `/dnd5v/`; CSS/JS подключаются через `/dnd5v/assets/...`; фон включён в `dist/character-sheet-parchment.png`.
- Локальный фон проверен визуально в браузере; локальный URL `/dnd5v/character-sheet-parchment.png` отвечает 200, браузер сообщает успешную загрузку изображения.
- В опубликованном фоне виден центральный тонкий ромб с линиями без прямоугольной подложки; края не мешают центральному тексту.
- В опубликованном фоне виден центральный тонкий ромб с линиями без прямоугольной подложки; края не мешают центральному тексту.
- Локальный browser smoke выполнен на точных viewport 1440×900, 1024×768, 800×800, 430×932 и 375×812. Проверены первый рендер, доступные вкладки, панель и ссылка опроса, создание/редактирование/сохранение/reload, замена с подтверждением, список черт и длинное название, а также ширина документа. Горизонтального overflow и console error/warning не обнаружено.
- Тестовые данные браузера создавались на отдельном `localhost` origin, не на `127.0.0.1` и не на опубликованном сайте. Тестовая черта удалена после проверки; тестовый персонаж оставлен только в изолированном origin.
- Атрибуты опроса проверены: точный URL, `target="_blank"`, `rel="noopener noreferrer"`. Ссылка открыла новую вкладку; форму не отправляли.

## Ограничения проверки

- В этой версии нет раздела «Отдых», Dice Roller, Initiative Tracker, бестиария, планировщика и компонентов. Проверить их поведение нельзя; они не добавлялись в рамках подготовки публичного тестирования.
- Есть вкладка «Магия / Заклинания» и редактирование ячеек заклинаний, но отдельного интерфейса параметров заклинаний в текущем источнике нет.
- Интерфейс чтения console доступен; отдельный сбор всех сетевых запросов/failed requests в browser automation не предоставлен. Для опубликованной сборки отдельно проверены HTTP-статусы HTML, JS, CSS, favicon и фона.
- На опубликованном домене обнаружилась сохранённая старая запись. Лист показал предупреждение о прежних персонажах/НПС, ничего не создавалось и не менялось в localStorage.
