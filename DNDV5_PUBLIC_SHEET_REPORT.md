# DNDV5 — публичный лист персонажа

## Изменения

- В верхней панели оставлена единственная пользовательская операция управления листом: «Создать персонажа».
- Добавлена кнопка «Пройти опрос» в том же ряду. Она открывает `https://forms.yandex.ru/u/6aec6367c45c070febaff5f5` в новой вкладке с `target="_blank"` и `rel="noopener noreferrer"`.
- Из интерфейса убраны список персонажей, создание НПС, копирование, удаление, импорт, экспорт и экспорт всех персонажей.
- Внутренние типы, storage, миграции, адаптеры и обработчики сохранены; скрыты только пользовательские controls.
- Empty state сохраняет рабочую кнопку создания персонажа. Сохранение, лист и редактирование активного персонажа не менялись.
