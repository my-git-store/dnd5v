# DND5V Character Sheet Rules

Работаем только над этим репозиторием.

Цель:
развитие D&D 5e листа персонажа.

Не изменять:
- Nastolka_backend
- my-table
- legacy API
- другие проекты вне текущего репозитория

Не расширять scope.

Перед изменениями:
1. изучить текущую структуру;
2. показать короткий план;
3. делать минимальные изменения.

После изменений:
- список файлов;
- проверки;
- краткий отчёт.

Сохранять текущую архитектуру проекта.

Не заменять mock/localStorage без отдельного решения.
