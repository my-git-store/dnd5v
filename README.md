# Nastolka D&D 5e Sheet — Фронтенд

Фронтенд-приложение на **Vue 3** (Composition API), **TypeScript**, **Vite** и **Tailwind CSS v4**.

---

## 🛠 Быстрый старт

```bash
npm install
npm run dev      # Разработка
npm run build    # Продакшн сборка (vue-tsc + vite build)
npm run preview  # Локальный запуск сборки
```

---

## 📂 Структура проекта

*   `src/assets/` — статика.
*   `src/composables/` — бизнес-логика, API, сокеты.
*   `src/styles/` — глобальные стили.
*   `src/ui/components/` — библиотека кастомных компонентов (UI-kit).

---

## 🧩 Описание UI-компонентов (`src/ui/components`)

*   **`CBtn`** — Кнопка с лоадером и поддержкой тем оформления (`primary`, `accent`, `delete`).
*   **`CAlert`** — Уведомления об успехе/ошибке.
*   **`CAvatar`** — Иконка/аватар пользователя или персонажа.
*   **`CCards`** — Карточки элементов (заклинания, инвентарь).
*   **`CCheckBox`** — Кастомный флажок/чекбокс.
*   **`CDropdown`** — Выпадающий список.
*   **`CEditor`** — Блочный редактор текста на базе EditorJS.
*   **`CFile`** — Загрузка файлов.
*   **`CForm`** — Обертка для форм.
*   **`CImage`** — Контейнер для изображений с ленивой загрузкой/заглушками.
*   **`CInput`** / **`CSelect`** / **`COption`** — Поля ввода и селекторы.
*   **`CLoader`** — Спиннер загрузки.
*   **`CModal`** / **`CModalRender`** — Динамическая система модальных окон.
*   **`CNotFound`** — Заглушка 404.
*   **`CPopup`** — Всплывающие подсказки / контекстные окна.
*   **`CScrollTopEl`** — Кнопка прокрутки наверх.
*   **`CShutter`** — Выезжающая шторка (боковая панель).
*   **`CSwiper`** — Слайдер/карусель элементов.
*   **`CTabs`** — Вкладки для переключения экранов.
*   **`CTooltip`** — Тултипы при наведении.
*   **`CValidate`** — Обертка для валидации полей ввода.
*   **`CWriteDeleteText`** — Компонент редактирования с возможностью удаления.

## ⚡ Композиблы (`src/composables`)

*   `useApiFactory.ts` — Фабрика типизированных клиентов Axios.
*   `useSocketFactory.ts` — Подключение и отправка событий WebSocket.
*   `tryCatch.ts` — Обертка для безопасного выполнения async/await.
*   `useCopyText.ts` — Копирование текста в буфер обмена.
*   `useFilters.ts` — Утилиты форматирования данных.
*   `useReqDefault.ts` — Настройки сетевых запросов по умолчанию.

## Лист персонажа

Демонстрационный лист находится в `src/modules/character-sheet`. Он использует четыре вкладки: «Основное», «Магия / Заклинания», «Инвентарь» и «БИО». Данные загружаются через `CharacterApi`, сейчас включён mock-адаптер с задержкой 500 мс и сохранением в versioned `localStorage`.

```bash
npm run build
```

Для проверки ошибки загрузки откройте приложение с `?mockLoadError=once`: первая загрузка покажет ошибку, а «Повторить» выполнит успешный запрос. Кнопка «Сохранить» сохраняет текущий черновик; после перезагрузки страницы он будет восстановлен.

Следующий адаптер может заменить `characterMockApi.ts` в `characterApi.ts`, сохранив методы `getCharacter` и `saveCharacter`. Компоненты листа при этом менять не потребуется.
