# DNDV5 — визуальный стиль листа

## Изменения

- Верхний декоративный разделитель переделан: прямоугольная подложка убрана, оставлены тонкий ромб и горизонтальная золотисто-бежёвая линия.
- Положение и размеры основного контента листа не менялись.
- Фоновая карта обработана без изменения композиции: сохранены parchment/sepiа палитра, пустой центр, замок, орнамент, компас и боковые рамки.
- Исходный фон был `1055×1491`; итоговый PNG — `2110×2982`.
- Для фона сохранён тот же mapping и имя файла, поэтому storage, API и логика приложения не затронуты.

## Browser smoke

На локальном `http://127.0.0.1:5173/` проверены первый рендер, новый ромб без прямоугольной подложки, фон, отсутствие горизонтального overflow и консоль. В свежей вкладке ошибок и предупреждений нет; фактический доступный viewport — `723×892`.

Точный override `1440×900`, `1024×768`, `800×800`, `430×932`, `375×812` недоступен в подключённом browser automation, поэтому эти размеры не выдаются за проверенные.
