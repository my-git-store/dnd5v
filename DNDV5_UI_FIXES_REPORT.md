# DNDV5 — UI fixes report

## Scope

Ветка: `feature/nastolka-demo-modules`.

Исправление ограничено Character Sheet и локальными игровыми компонентами. Backend, API, storage, migration и доменная логика бросков не менялись.

## Изменения

- В блоке «Спасброски» поле «Добавка» и карточка «Итог» выровнены по нижней границе поля. Значение и подпись внутри карточки центрируются вертикально; мобильная раскладка сохранена.
- В карточках атак колонки «Атака», «Урон» и «Дальность» выравниваются от верхней границы grid-строки. Высота названия и дополнительных тегов больше не сдвигает соседние заголовки.
- Пользовательские подписи игрового раздела переведены на русский: «Демо», «Локальный компонент», «Бросок кубиков», «Трекер инициативы», «Готово» и состояние активного броска.
- Семь PNG кубиков (`d4`, `d6`, `d8`, `d10`, `d12`, `d20`, `d100`) проверены визуально. Встроенных подписей с названиями граней нет, поэтому assets не изменялись.

Изменённые файлы:

- `src/modules/character-sheet/styles/character-sheet.css`
- `src/modules/table-components/TableComponentsShowcase.vue`
- `src/modules/table-components/components/dice/DiceRoller.vue`
- `src/modules/table-components/components/initiative/InitiativeTracker.vue`
- `DNDV5_UI_FIXES_REPORT.md`

## Browser smoke

В доступной вкладке `http://127.0.0.1:5173/` проверены:

- вкладки «Основное», «Бой» и «Игровые компоненты»;
- визуальное выравнивание блока «Итог»;
- выравнивание заголовков атаки;
- русские пользовательские подписи и состояния;
- выбор каждого типа d4, d6, d8, d10, d12, d20 и d100;
- смена изображения при выборе d4;
- rolling/landing для d100 с числовым результатом и новой записью истории;
- Initiative Tracker и кнопка перехода хода;
- отсутствие видимого горизонтального переполнения в текущем окне.

Текущий browser API не предоставляет точное изменение viewport и чтение console. Поэтому отдельные проверки именно на `1440×900`, `1024×768`, `430×932`, `375×812`, а также отсутствие console errors не выдаются за выполненные.
