# DNDV5 — Dice Caption Cleanup Report

## Изменения

- Убраны видимые подписи под визуальным кубиком: «Готова к броску», «Кость вращается…» и «Бросок завершён».
- Статусный `span.die-stage-caption` сохранён в DOM с `aria-live="polite"`, но теперь визуально скрыт доступным способом. Это сохраняет объявления для screen reader без пустого визуального блока.
- Числовой результат на грани, история, кнопки броска/очистки и fallback-ветка `RollingDie` не изменялись.

Изменённый файл:

- `src/modules/table-components/styles/table-components.css`

## Проверка в браузере

В доступном браузере проверен фактический viewport `1625 × 892` (контентная ширина `1610px`). Переключение точных размеров `1440 × 900`, `1024 × 768`, `800 × 800`, `430 × 932` и `375 × 812` через доступный browser API не поддерживается, поэтому эти размеры не выдаются за проверенные.

В фактически доступном viewport проверены:

- переключение d4, d6, d8, d10, d12, d20 и d100 — каждый тип загружает соответствующий asset;
- idle-состояние без видимой подписи под кубиком;
- rolling-состояние и landing;
- числовой результат `d100` и запись в историю;
- очистка истории и empty state;
- отсутствие горизонтального overflow (`scrollWidth` не превышает ширину viewport);
- отсутствие ошибок и предупреждений в console.

Проверка искусственного отказа PNG отдельно не выполнялась: browser API не предоставляет безопасную перехватку asset-запросов в текущем окружении. Код fallback в `RollingDie` не менялся.
