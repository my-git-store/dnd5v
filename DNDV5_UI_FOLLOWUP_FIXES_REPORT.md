# DNDV5 — Follow-up UI Fixes Report

Дата: 2026-10-18
Репозиторий: `dnd5v`
Ветка: `feature/nastolka-demo-modules`

## Исправления

- Пересобрана общая сетка заголовка и строк спасбросков. `Добавка` и `Итог` используют одинаковые колонки, значения больше не выталкивают строку за ширину панели.
- Числовые значения боевого блока и карточек атак получили единый акцент: tabular numerals, увеличенный размер и единый вес шрифта.
- Loader получил отдельный центрированный контейнер с минимальной высотой и адаптивным размером. После загрузки компонент по-прежнему полностью удаляется из DOM.
- В списках атак и заклинаний длинные описания показываются одной строкой с ellipsis; полный текст остаётся в редакторе. Источник навыка также не раздвигает строку.
- Модалка черты получила отдельный responsive-класс: textarea увеличена до удобной высоты, сохраняет перенос текста, прокручивается внутри viewport, а действия могут безопасно переноситься.
- Список черт продолжает показывать только название и действия; описание не удаляется из модели, draft или storage.

## Browser smoke

В доступном in-app browser проверены:

- все вкладки Character Sheet: «Основное», «Бой», «Магия / Заклинания», «Инвентарь», «БИО», «Игровые компоненты»;
- отсутствие DOM-переполнения после исправления спасбросков: до правки строки были шире панели на 20 px, после правки overflow отсутствует;
- визуальное выравнивание `Добавка` / `Итог`;
- визуальное увеличение чисел в боевом блоке и атаках;
- модалка черты: одна колонка, textarea 180 px, кнопки не перекрываются;
- навигация и длинные подписи мастера создания персонажа;
- отсутствие горизонтального overflow страницы в доступном viewport;
- browser console через доступный dev-log API: новых `error` и `warn` не обнаружено.

Точные размеры `1440×900`, `1024×768`, `800×800`, `430×932`, `375×812` недоступны для программной установки текущим browser API. Поэтому отдельные проверки именно этих viewport не объявляются выполненными. Loader проверен по реализации и layout-контейнеру; краткое переходное состояние загрузки недоступно для стабильного захвата после готового первого рендера.
